# NullDox - 随机句子头像插件

## 简介

NullDox 是一个用于 AstrBot 的娱乐插件。新版不生成手机号、IP、地址或地图等任何开盒样式信息，只会按词库随机输出一句话，并附带目标用户头像。

输出格式：

```text
用户:XXX(ID:xxx)
随机句子
[头像]
```

其中 `XXX` 优先使用 AIOCQHTTP 事件中的群名片/昵称。如果名称为空或名称与 ID 相同，会改为：

```text
ID:xxx
随机句子
[头像]
```

## 功能

- 主动查询：通过 `/盒 [QQ号]` 或 `/盒 [@用户]` 输出随机句子和头像。
- 自动触发：检测到群成员主动退群时，自动输出该用户的随机句子和头像。
- 公共词库：所有群聊通用。
- 分群词库：指定群号可配置额外句子。
- 合并抽取：群聊命中分群词库时，会把公共词库和该群词库合并后随机抽一句。

## 使用

主动查询：

```text
/盒 123456789
/盒 @用户
```

返回示例：

```text
用户:群友昵称(ID:123456789)
今日鉴定结果：适合继续水群。
[头像]
```

退群触发时也使用同样格式。

## 配置

默认无需配置即可使用。可在插件配置中调整公共词库和分群词库。

公共词库：

```json
{
  "sentence_library": {
    "global_sentences": [
      "你已被随机句子命中。",
      "资料检索失败，但头像看起来很有故事。"
    ]
  }
}
```

分群词库：

```json
{
  "group_sentence_rules": [
    {
      "group_id": "123456789",
      "sentences": [
        "本群特供文案 A",
        "本群特供文案 B"
      ]
    }
  ]
}
```

当群号为 `123456789` 时，插件会从 `global_sentences + sentences` 的合并结果中随机抽取。

## 权限与监听过滤

保留原有过滤配置：

| 配置项 | 作用 |
| --- | --- |
| `user_list_mode` | `/盒` 主动命令的白名单、黑名单或不限制 |
| `user_list` | 主动命令账号列表 |
| `group_list_mode` | 退群监听的群聊白名单、黑名单或不限制 |
| `group_list` | 退群监听群聊列表，支持纯群号或 AstrBot UMO |

## 常见问题

### 退群事件为什么不触发？

- 使用 AIOCQHTTP 协议适配器。
- 机器人需要能收到群通知。
- 只监听主动退群 `leave`，不处理被踢出事件。
